# Morning-Runner + Exit-Timing study

_Informational / educational only - not investment advice._

Trigger: open gaps up >= 20% vs prior close (seen at 9:30, no close-selection bias). Entry = 09:30 open. Sample: 1880 gap-up events, small/micro US, ~2 yrs.

## Which exit made money? (return per trade, entry at the open)
| Exit rule | mean % | median % | win rate |
|---|---|---|---|
| Sell at 30-min high (ideal cap) | +10.74 | +6.85 | 92.8% |
| Exit 10:00 | -0.96 | -2.5 | 38.4% |
| Exit 10:30 | -1.18 | -3.2 | 38.5% |
| Exit 11:00 | -0.73 | -3.36 | 38.1% |
| Exit 11:30 | -0.5 | -3.52 | 38.8% |
| Exit 12:00 (noon) | +0.46 | -2.71 | 38.9% |
| +10% target, else noon | -0.19 | +5.02 | 56.1% |
| +20% target, else noon | -0.61 | -1.48 | 44.4% |
| 10% trailing stop | +0.88 | -1.95 | 38.8% |
| 15% trailing stop | -1.61 | -3.9 | 34.4% |
| -10% stop, else noon | -0.63 | -10.0 | 29.8% |
| +15% / -10% bracket | -1.37 | -10.0 | 36.1% |
| Hold to close (baseline) | +263.7 | -3.76 | 40.9% |

**Best realistic expectancy:** Hold to close (baseline) (+263.7% mean/trade). Worst: 15% trailing stop (-1.61%).
