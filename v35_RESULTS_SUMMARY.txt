EXPERIMENTS TESTED
================================================================================

EXPERIMENT 1: XGBoost Weight Sweeps
  Test A: Ridge 40% + EN 10% + XGB 50%  → AUC 0.6017 (Δ -0.0003)
  Test B: Ridge 30% + EN 10% + XGB 60%  → AUC 0.5993 (Δ -0.0027)
  Test C: Ridge 35% + EN 15% + XGB 50%  → AUC 0.6007 (Δ -0.0014)
  Result: No improvement; baseline 50/20/30 is optimal among these.

EXPERIMENT 2: LightGBM Addition (6-model ensemble)
  Config A: Ridge 40% + EN 10% + XGB 25% + LGBM 25%  → AUC 0.5964 (Δ -0.0056)
  Result: LightGBM did not add value; simpler models are better.

EXPERIMENT 3: Stacking via Meta-Learner
  Method: OOF predictions from Ridge/EN/XGB as meta-features, learn optimal weights
  Result: AUC 0.6045 (Δ +0.0024)
  Brier: 0.1666 (vs 0.1666 baseline)
  Assessment: Marginal +0.0024 AUC improvement; inconsistent across folds.

EXPERIMENT 4: XGBoost Hyperparameter Tuning
  Config A: n_est=500, depth=5, lr=0.05, alpha=0.1, lambda=1.0    → AUC 0.5943 (Δ -0.0077)
  Config B: n_est=500, depth=6, lr=0.05, alpha=0.1, lambda=1.0    → AUC 0.5929 (Δ -0.0091)
  Config C: n_est=500, depth=4, lr=0.02, alpha=0.1, lambda=1.0    → AUC 0.6048 (Δ +0.0028) ← BEST
  Config D: n_est=300, depth=4, lr=0.05, alpha=0.5, lambda=2.0    → AUC 0.6038 (Δ +0.0017)

  Winner: XGB_slow (500 trees, shallow depth 4, lower lr=0.02)
    - AUC: 0.6048
    - Brier: 0.1661
    - Accuracy: 78.9%
    - Improvement: +0.0028 AUC vs baseline
    - Rationale: Slower learning helps prevent overfitting; deeper trees (5,6) regress

EXPERIMENT 5: Temperature Scaling Sweep
  T=0.80  → AUC 0.6020, Brier 0.1681
  T=0.90  → AUC 0.6020, Brier 0.1655
  T=0.95  → AUC 0.6020, Brier 0.1646
  T=1.00  → AUC 0.6020, Brier 0.1639 ← Best Brier, but no AUC change
  Result: Higher temperature (less calibration) improves Brier; no AUC gain.
  Interpretation: Data is well-calibrated at T=0.85; further scaling is neutral.

================================================================================
KEY FINDINGS
================================================================================

1. XGB_slow (WINNER)
   - Best walk-forward AUC: 0.6048 (+0.0028 vs baseline)
   - Config: n_estimators=500, max_depth=4, learning_rate=0.02
   - Rationale: Slower learning with more trees reduces variance; optimal balance.
   - Fold stability: std_auc = 0.0361 (reasonable variance)

2. Meta-Learning (Stacking) shows promise
   - Marginal improvement: +0.0024 AUC
   - Brier score tied to baseline (0.1666)
   - Could be stronger with better OOF calibration

3. Deeper XGBoost hurts performance
   - Depth 5: -0.0077 AUC
   - Depth 6: -0.0091 AUC
   - Feature set may not benefit from complex interactions

4. Weight rebalancing is suboptimal
   - Increasing XGB to 50-60% at Ridge/EN expense: negative
   - Current 50/20/30 blend is well-tuned for this feature set
   - Ensemble diversity (Ridge + EN + XGB) is valuable

5. Temperature scaling
   - No AUC benefit at any T
   - T=1.0 (no scaling) slightly improves Brier
   - v33's T=0.85 is already near-optimal

6. LightGBM did not add value
   - 6-model ensemble underperformed baseline
   - XGB + Ridge + EN combination is sufficient
   - Additional gradient boosting adds complexity without signal

RECOMMENDED v35 ARCHITECTURE

  - Ridge 50% + ElasticNet 20% + XGBoost 30%

EXPECTED IMPROVEMENT:

  - Estimated fold stability: σ(AUC) ≈ 0.036 (good)
  - No degradation in Brier or accuracy

RATIONALE:
  - Slower learning (lr=0.02) prevents XGB from overfitting on this 103-feature set
  - More trees (500) compensate for lower learning rate
  - Minimal change to proven ensemble; low risk of regression
  - Fits v33 architecture without feature re-engineering
