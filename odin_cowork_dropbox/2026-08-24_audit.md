> *"Date extended: announced August 24, 2026. The FDA moved this target action date **from November 22, 2026 to November 22, 2026**."*

**Same date on both sides.** The prior goal date was **2026-08-22** — the date I've been tracking on this name all month. The "from" value has been overwritten with the new one, so the sentence now says the date moved from X to X.

This is reader-facing, on a page about a name in the portfolio, and it's the kind of claim an AI engine will lift. **Severity S3** — the underlying data is right (`2026-11-22`, `Upcoming`, `updated_at 2026-08-22`; the page shows "Nov 22" ×4 and "Aug 22" ×0), so it's a template bug in the extension-disclosure text, not a data error.

**Fix:** capture the prior date before the write and render it, and add a guard rejecting any "moved from X to Y" where X == Y. Mechanical, no judgement.
