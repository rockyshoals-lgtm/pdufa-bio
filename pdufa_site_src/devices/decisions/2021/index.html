How to read the decision column

PMA decisions use the FDA's own four-letter codes. openFDA's PMA field reference defines APPR as approval, APWD as withdrawal after approval and APRL as reclassification after approval. Every PMA row here carries an FDA approval order dated the decision date shown; the FDA record page shows any later status. A code the reference does not define (APCB) is printed with that note. The FDA's De Novo record pages print DENG as "Decision granted". Review days are calendar days from the date the FDA records the submission as received to its decision date; for a supplement they count from the supplement's own receipt.
