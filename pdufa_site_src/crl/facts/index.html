FDA Complete Response Letters: facts from the release

Page updated November 22, 2026·next FDA decision on the calendar ·Data as of Nov 23, 2026 4:09 AM ET

The FDA has released 466 records under its CRL transparency program (openFDA, last updated 2026-11-18; snapshot read 2026-11-22). 1 of them repeats another record (same date, application numbers and text), leaving 465 distinct records. 452 are Complete Response Letters dated 2009 to 2026. Each count below says which files it comes from and how it is made, so anyone can redo it. Counts and date differences only: no approval rates, no predictions. Every letter, by year; every CRL, by company; which FDA office signed each; what the letters say, term by term; new letters by feed.

Download every letter as data: CSV · JSON (452 rows, one per distinct letter; the 2 the FDA rescinded as issued in error are flagged). A dated copy is kept for each FDA release (2026-06-22, 2026-08-26, 2026-11-18). Free under CC BY 4.0: cite pdufa.bio and link this page.

What the 2024+ letters name as deficient

165 Complete Response Letters dated 2024 or later have a PDF of their own. 163 of them have a text layer we read; 94 carry at least one deficiency section heading in the FDA's own words (labeling, safety update and other administrative sections set aside). The other 69 carry no deficiency heading that the extractor recognizes yet, so they are left out of the table rather than guessed; they are read again as its vocabulary grows. Letters the FDA rescinded

How this page is made

Inputs: the FDA's CRL release (openFDA transparency/crl, snapshot 2026-11-22), the section headings each PDF's text layer carries (_crl_headings.json), the Orange Book products file (_orange_book/products.txt), and this site's decision pages. The script is build_crl_facts.py in the site's public repository; it runs on every rebuild. A letter the FDA released twice (same date, application numbers and text) is counted once.
