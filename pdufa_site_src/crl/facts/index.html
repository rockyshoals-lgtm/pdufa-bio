FDA Complete Response Letters: facts from the release

Page updated November 27, 2026·next FDA decision: on the calendar·Data as of Nov 27, 2026 8:36 PM ET

The FDA has released 467 records under its CRL transparency program (openFDA, last updated 2026-11-18; snapshot read 2026-11-25). 1 of them repeats another record (same date, application numbers and text), leaving 466 distinct records. 453 are Complete Response Letters dated 2009 to 2026. Each count below says which files it comes from and how it is made, so anyone can redo it. Counts and date differences only: no approval rates, no predictions. Every letter, by year; every CRL, by company; which FDA office signed each; what the letters say, term by term; days from receipt to each letter, by the letters' own dates; new letters by feed.

Download every letter as data: CSV · JSON (453 rows, one per distinct letter; the 2 the FDA rescinded as issued in error are flagged). A dated copy is kept for each FDA release (2026-06-22, 2026-08-26, 2026-11-18, 2026-11-18 read 2026-11-25). Free under CC BY 4.0: cite pdufa.bio and link this page.

What the 2024+ letters name as deficient

166 Complete Response Letters dated 2024 or later have a PDF of their own. 164 of them have a text layer we read; 94 carry at least one deficiency section heading in the FDA's own words (labeling, safety update and other administrative sections set aside). The other 70 carry no deficiency heading that the extractor recognizes yet, so they are left out of the table rather than guessed; they are read again as its vocabulary grows. From the last released CRL to approval (BLAs approved since January 2025)

The Orange Book leaves out BLAs, so the NDA count above has none. Drugs@FDA (openFDA drugsfda, read 2026-11-27) lists the approval of the first original submission (ORIG-1), dated January 1, 2025 or later, for 17 BLAs that have a Complete Response Letter in the release dated before it, on the same application number. Days from the last such letter to that approval: median 275, shortest 190, longest 1530.

Only approvals since January 2025 are read, so this lists those 17 BLAs; it is not a count of how long every released BLA letter took to end in an approval. The release holds original-application CRLs for 96 BLAs. 3 more BLAs with a Drugs@FDA original approval dated on or before the last letter are left out. 2 more are left out because the approval read is a second original submission (ORIG-2 or later), and the first may have been approved before January 2025. openFDA's approval_status field labels 13 of these 17 letters "Unapproved"; Drugs@FDA dates each of those approvals before openFDA's last update (2026-11-18).

How this page is made

Inputs: the FDA's CRL release (openFDA transparency/crl, snapshot 2026-11-25), the section headings each PDF's text layer carries (_crl_headings.json), the Orange Book products file (_orange_book/products.txt), and this site's decision pages. The script that builds it runs on every rebuild. A letter the FDA released twice (same date, application numbers and text) is counted once.
