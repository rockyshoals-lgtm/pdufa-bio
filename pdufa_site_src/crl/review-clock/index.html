Days from receipt to a CRL, by the letters' own dates

Page updated November 23, 2026·next FDA decision on the calendar ·Data as of Nov 25, 2026 1:28 AM ET

Of the 450 Complete Response Letters in the FDA's release (rescinded letters left out), 220 are on an original application, name no earlier FDA action, and print the date the FDA received the application (or, for 6, only the date it was dated or submitted). From that date to the letter: median 304 calendar days, middle half 297 to 353.5, shortest 177, longest 1453. 92 letters answer a response to an earlier FDA letter and print both dates: median 181 days from the response to the letter. These are days between printed dates, not FDA review time.

Read from the text of the 450 distinct Complete Response Letters in the FDA's CRL release (openFDA transparency/crl, last updated 2026-11-18; snapshot read 2026-11-22), the same letters as /crl less the 2 the FDA rescinded as issued in error. Most CRLs open with a form sentence: "Please refer to your new drug application (NDA) dated and received [date] ...". A letter on a resubmission adds: "We acknowledge receipt of your amendment dated [date], which constituted a complete response to our [date] action letter." This page takes those printed dates and counts the calendar days between them and the letter's own date. That is not the FDA's review time: the FDA's clock can stop, restart or be extended, and the letters print only some of that (a letter that says a submission extended the goal date is counted below). Counts of dates only, and no reading of why.

From receipt to the letter, where no earlier FDA action is named

Letters on an original application (not a supplement) that print the date the application was received and name no earlier FDA action on it (no action letter answered, no refuse-to-file letter, no resubmission, no tentative approval, no rescinded approval) before the words "completed our review", and for whose application number the release holds no earlier CRL. A letter can still leave out an earlier action it does not name. 6 of the 220 print no received date, only the date the application was dated or submitted, used as printed. Days are calendar days from that date to the letter's date.

After a response to an earlier FDA letter

Letters on an original application that print the date of a response ("amendment", "resubmission" or "submission") and the date of the earlier FDA letter it answered (an action letter, a Complete Response Letter, a tentative approval). Where a letter lists several, the latest dated response is used, with the latest earlier letter it lists. The earlier letters, as the letters name them: 90 action letters; 1 complete response letter; 1 tentative approval letter. For 84 of these 92 letters, the release also holds a Complete Response Letter of that earlier date on the same application number; for the other 8 it holds none of that date.
