## Standing red-team date audit protocol (lock in)

Going forward, every catalyst added to the portfolio must pass these four checks BEFORE position sizing:

1. **Primary source verification** — company press release OR conference official schedule. Not a secondary news aggregator alone.
2. **Day-of-week sanity check** — match claimed date to actual calendar day (e.g., Apr 20 2026 = Monday; CDT time zone for Chicago AAN).
3. **Conference venue/year cross-check** — confirm conference is the current-year edition, not prior-year (AACR 2025 vs 2026 is a common trap).
4. **Presentation type + session ID logged** — oral / late-breaking / poster / minisymposium + abstract number stored in CLAUDE.md so we can re-verify post-hoc.

Any catalyst without all four is flagged `DATE_UNVERIFIED` and not traded.
