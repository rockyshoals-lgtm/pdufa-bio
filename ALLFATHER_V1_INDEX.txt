  Strategy: Fit encoder on train, apply to val/test (no leakage)

  Names: sponsor_prior_approvals, adcom_vote_pct, ta_base_score, historical_crl_rate, etc.

    • adcom_vote_pct: NaN → -1 (indicator: no adcom meeting)
    • resubmission_class: NaN → 0 (indicator: first submission)

  Strategy: Fit scaler on train, apply to val/test (no leakage)

TARGET ENRICHED SCHEMA (38 columns):

BASE COLUMNS (10):
  Ticker, Name, Drug, Indication, Stage, Catalyst Date, Catalyst,
  date, outcome, year

CTGOV TRIAL DESIGN (10):
  Source: ClinicalTrials.gov API v2 (real data, 83% coverage)
  • ctgov_num_arms — number of trial arms (0–4)
  • ctgov_has_placebo — placebo control (binary)
  • ctgov_masking_rigor — Open/Single/Double masking score
  • ctgov_enrollment — actual trial enrollment (log scale)
  • ctgov_has_os_endpoint — primary endpoint = OS (binary)
  • ctgov_has_orr_endpoint — primary endpoint = ORR (binary)
  • ctgov_eligibility_strictness — criteria complexity score
  • ctgov_sponsor_scale — Individual/Organization/Company
  • ctgov_real_enrollment — actual enrolled participants (log)
  • ctgov_has_withdrawals — trial has withdrawals (binary)

DRUG JOURNEY (16):
  Sponsor + drug historical success metrics
  • sponsor_prior_phase_success_rate, sponsor_ta_specialization
  • sponsor_prior_phase_outcome, sponsor_positive_streak
  • sponsor_overall_success_rate, sponsor_phase_progression
  • sponsor_indication_specificity, sponsor_stage_experience
  • drug_prior_phase_success_rate, drug_prior_phase_outcome
  • drug_positive_streak, drug_stage_progression
  • drug_ta_specialization, drug_mechanism_alignment
  (8 sponsor + 6 drug = 14 features, plus interactions)

FINANCIAL (6):
  Source: FinBrain API at T-1 (day before catalyst)
  • price_at_t_minus_1 — stock price 1 day before event
  • market_cap — market capitalization
  • volume_avg_30d — 30-day average volume
  • volatility_30d — 30-day price volatility
  • beta — relative to market
  • analyst_rating — consensus rating

NLP CATALYST (5):
  Text analysis of Catalyst description
  • catalyst_sentiment — positive/negative tone score
  • catalyst_phase_keywords — presence of phase-specific language
  • catalyst_efficacy_signals — efficacy-related language
  • catalyst_safety_concerns — safety-related language
  • catalyst_regulatory_flags — regulatory keywords

CTGOV INTERACTIONS (3):
  Combinations of CTGOV features
  • ctgov_placebo_x_enrollment — harder protocol × larger trial
  • ctgov_os_x_masking — OS endpoint × masking rigor
  • ctgov_enrollment_x_strictness — enrollment × strict criteria
